## What the game told us (all checked live; details in `reference/`)

- **Enchant Road writes `0x18`** (road bit kept, `0x10` added). Myrror's roads are `0x18` too, not a bare
  `0x10` (our docs said otherwise until 2026-10-06). [kazzmir-save-layouts.md](../reference/kazzmir-save-layouts.md)
- **A meld is one byte**: a node record's owner (`+3`). There is no separate "melded" flag. Its guardians
  are cleared separately in the encounter record.
- **Node sparkles ripple**: tile *i* of the aura list shows frame `(step + i) mod 6`. **Enchanted roads do
  not**: every tile is on one frame. Both are `MAPBACK` art, in the sprite catalog.
- **The game's animation step is about 0.6 s.** STORY-007 first guessed 160 ms; the measurement is in
  [classic-terrain-format.md](../reference/classic-terrain-format.md) and `terrain_animation.mjs`.
- **Reveal all leaves a site's looked-at flag alone**; a revealed lair still says "Unexplored".
- The game accepts every byte Mirror writes for these edits and keeps it (RAM equals the file after Load Game).
- The live-RAM findings and a recipe for measuring an animation from screenshots:
  [live-ram-map.md](../reference/live-ram-map.md), "Findings, 2026-10-06/07".

## How we work now

- **Kevin merges.** Agents branch, push and open the PR. A PR stacked on another branches from it but targets `main`.
- **Copilot reviews each PR**, and Kevin leaves review comments on GitHub too. Fix each finding or say why not, reply on
  the thread (or the PR), and say what was checked. Several real bugs came out of this loop (a lost-update race between tabs, a sprite decode that
  repeated, a test helper matching every event).
- **Real-game checks use the fork's API**, and `scripts/live_session.sh start` opens the game (it needs a person at the
  keyboard). Build the test save with Mirror's own code, diff it against its source, load it, read the same bytes back
  from RAM, compare screenshots with Mirror's decoded sprites, then ask a person to look.
