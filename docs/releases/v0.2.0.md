# Mirror v0.2.0

Mirror is a viewer and editor for classic *Master of Magic* (1994 DOS) save files, a Phoenix/LiveView app that runs on your own machine and opens in your browser. Source only: there is no published Docker image.

This release is mostly about **getting a save in and out**, and about the wizard page feeling like a normal form. It also adds Windows and Steam.

## What's new

- **A start page and your save slots.** Open Mirror, choose your game folder once, and click the save you want, with no copying files around and no typing paths. Slots that have a save are green, empty ones are grey, and the autosave (slot 9) opens too. Chrome remembers the folder; if it asks again there is a **Reconnect folder** button.
- **Save to a slot from the header.** Every page has the same header now: the Arcanus and Myrror tabs, a pill for each wizard in the save, an **Unsaved changes** badge, and **Save to** with the slots 1 to 8. Replacing a save that is already there asks first, and the old file is kept as `SAVEn.GAM.mirror-backup` (the game ignores it). A slot with no name in the game's Load Game list gets one ("Mirror Edit Slot 3"), so it does not show up blank. The autosave slot is never written to.
- **The wizard page has no Apply buttons.** Change a field and it applies: a dropdown or a tick at once, a number or a name when you leave the box. Each change is one undo step, and **Undo** and **Redo** are in the header. Artifact lists are priciest first and heroes are alphabetical.
- **Messages that behave.** One stack in the bottom right: the newest in front, the older ones tucked behind, each fading by itself (an error stays longer), and pointing at the stack holds them. A wizard edit's message has an **Undo** button.
- **Windows, and a Steam copy.** Mirror was set up and tried on Windows 11 with the Steam version (*Master of Magic Classic*). It works. The import warns that three files (`MAPBACK.LBX`, `ITEMPOW.LBX`, `ITEMDATA.LBX`) differ from GOG's; they were tested and work, so the warning can be ignored. The README has a Windows section, and there is a PowerShell version of the live-session script.

## Fixed

- On a real save with a fame above 30000 (the game itself writes 30001), the wizard page's Apply did nothing and said nothing, because the browser's own form check blocked it. Gone with the buttons: a value that is already in the save is left alone, and a refused value says why.
- Several file-path bugs on Windows (saving and the path tests).

## Changed (read this if you used v0.1.0)

- **Chrome or Edge is needed to open and save a game.** The folder picker is theirs. Firefox and Safari can't open a save any more: the path box (on the map page and in the Lab) and **Save as** are gone. The server no longer reads or writes your saves by path at all, so this works the same from Docker.
- Saving over an existing slot is now allowed, with a warning and a backup. v0.1.0 never overwrote the save you opened.
- The old home page is the start page now.

## Known limits

- **GOG 1.31** is the version every edit was checked against. The Steam version loads, draws, and a save edited in Mirror loads in its game; its three differing files were tested.
- The raw tile tools (Cycle, Paint tile) do not keep landmass ids consistent. Use Paint type for coasts. Nothing yet warns about impossible states.
- Time Stop cannot be edited. Hero ability names and experience thresholds are not shown. Renaming a hero was not checked against the hero-name table at the end of the save.
- Items: the editor refuses an item in a place of the wrong kind, though the game accepts it. Giving things between wizards and dismissing heroes are left to the game.
- Save from Mirror with the game closed: the game rewrites its slot-name list when it quits, and *probably* undoes Mirror's name for a slot if it is open at the time (not tested).
- The map's toasts cover the layers panel for a few seconds when they show.

## Install

You need Elixir 1.20.4 / Erlang/OTP 29.1 (or Docker), **Chrome or Edge**, and **your own copy of the game**: Mirror does not include game files.

```bash
git clone https://github.com/ApocryphaCipher/Mirror.git
cd Mirror
mix setup
mix mirror.import_game "/path/to/your/Master of Magic"
bash scripts/dev_server.sh        # then open http://localhost:4000
```

Or with Docker (builds the image on your machine): `docker compose up --build`. On Windows see the README. Details are in the [README](../../README.md).

If you already ran v0.1.0 there is nothing to migrate: `~/.mirror/game` still holds the game's data files. Open Mirror and choose your game folder (the one the game saves into) on the start page.
