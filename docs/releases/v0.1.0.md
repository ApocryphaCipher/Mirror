# Mirror v0.1.0

The first release. Mirror is a viewer and editor for classic *Master of Magic* (1994 DOS) save files, a Phoenix/LiveView app that runs on your own machine and opens in your browser. Source only: there is no published Docker image.

## What it does

- **Map pages** (`/arcanus`, `/myrror`): the overland map drawn with the game's own art (terrain, cities, units, towers, lairs, nodes, roads, specials, corruption, fog of war), view mode with zoom, pan and a hover readout, and layer toggles.
- **Map editing:** paint terrain (the Paint type tool keeps coasts and landmass ids right), roads, corruption, specials, reveal the map, move cities, towers, lairs, nodes and unit stacks, edit a city, lair, node or unit. Undo and redo cover everything. **Save as** never overwrites the save you loaded.
- **Wizard pages** (`/wizard/1` to `/wizard/5`): name, gold, mana, fame, books, retorts, spells, research, relations and global enchantments (all but Time Stop); heroes (name, level, experience, damage, and adding a hero to an empty place); artifacts (edit, move between a hero's places and the vault, fill a place from the premade items, remove); and a lair's item count.
- **Research tools:** the Lab (raw layers) and the tile probe (an LBX explorer).

Every editor was checked by loading the saved file in the real game (DOSBox).

## Known limits

- Only the **GOG 1.31** game was tested. A Steam copy has not been tried.
- The raw tile tools (Cycle, Paint tile) do not keep landmass ids consistent. Use Paint type for coasts. Nothing yet warns about impossible states (a land army under new ocean, and so on).
- Time Stop cannot be edited. Hero ability names and experience thresholds are not shown. Renaming a hero was not checked against the hero-name table at the end of the save.
- Items: the editor refuses an item in a place of the wrong kind, though the game accepts it. Giving things between wizards and dismissing heroes are left to the game.
- Saves only load in the game as `SAVE1.GAM` to `SAVE9.GAM`.

## Install

You need Elixir 1.20.4 / Erlang/OTP 29.1 (or Docker), and **your own copy of the game**: Mirror does not include game files.

```bash
git clone https://github.com/ApocryphaCipher/Mirror.git
cd Mirror
mix setup
mix mirror.import_game "/path/to/your/Master of Magic"
bash scripts/dev_server.sh        # then open http://localhost:4000/arcanus
```

Or with Docker (builds the image on your machine): `docker compose up --build`. Details are in the [README](../../README.md).
